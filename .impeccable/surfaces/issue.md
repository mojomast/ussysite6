# Issue 01 layout

Primary target: `index.html`. Related: `index.css`, `publication.css`, `page-reader.css`, `js/app.js`, `js/cover-plate.js`, `js/page-reader.js`.

Mode: **Read**, with an artwork-led cover. Code-led implementation using existing authored imagery. Product and brand constraints are recorded in `PRODUCT.md`.

## Direction contract

**THESIS:** A source-linked software magazine whose large, strange mechanical still lifes and varied story settings invite reading. Replace the portal-like cover and repeated product-card silhouette.

**OWN-WORLD:** Retain Darkroom's warm charcoal and ink, the Si. masthead, original biomechanical cover and the six established font families. Large art and purposeful type carry the identity; ordinary facts and utilities have quiet, open framing.

**STORY:** Browse the cover and contents; read eleven distinct projects; inspect screenshots, studies and repository evidence; collect useful repositories in the Source Room.

**FIRST VIEWPORT:** Masthead above a dominant, unobstructed original cover plate and a restrained rail of four cover stories. Reader navigation is compact. Features alternate among plate-led opener, technical report and essay settings.

**FORM:** User-pinned magazine/spread identity, refined through editorial research and the existing artifact. No concept seed was run; the text-only skill integration uses direct code and project context.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Responsive and interaction contract

Narrow screens compose a single-column sheet before Fit/Fill geometry is measured. Zoom changes scale and the viewing window, never the composition. Page turns, disclosure animation, source access, search, saved projects, sound, image enlargement, print and reduced motion remain functional. Existing raster provenance lives with the assets' Blender scripts, rebuild notes and screenshot captions.
