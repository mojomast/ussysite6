# SLOP ILLUSTRATED

SLOP ILLUSTRATED (Si.) is a source-linked digital magazine about eleven software projects by **SLOPTIMUS PRIME**. The publication lives at https://ussy.host and its repository is https://github.com/mojomast/ussysite6.

## Readers and purpose

Software builders and curious readers should be able to browse the issue, understand a project's actual contribution, inspect its interface and sources, and follow its repository. The artwork provides a memorable interpretation of the subject; it does not supply evidence of software behavior.

## Product truth

- Fourteen digital folios: cover, contents, eleven features, Source Room.
- A biomechanical Blender cover, twelve editorial Blender plates, six screenshots and five interactive SVG studies.
- Each feature has pinned references and a genuine repository excerpt. Project claims must remain source-supported. JamMate's playing-state capture is a mock fixture; Warpi adds Pi-agent/BYOK integration to Warp's inherited terminal interface.
- Source Room offers saved projects, local notes and Markdown export. The existing API state is shared; localStorage also preserves reader state.
- Continuous scrolling and a full-screen, animated page reader. Fit shows the whole sheet. Fill smoothly scales the same composition. Engineering details unfold inside Under the hood.
