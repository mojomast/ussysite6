Folio 02 · Frontispiece
A letter from the editor

Show the work. Credit the floor you’re standing on.

This is the first issue of a magazine about software made by one person and a rotating crew of agents, written with AI help, edited by someone whose name is a Transformers pun. You are allowed to find that funny. We do.

The rule for every feature is simple and slightly annoying: say what the project actually adds, say what it stands on, and link the commit. So JamMate is introduced as an addition to Raphael Fukuda’s Guitar Companion. Warpi begins by crediting Warp for the terminal. Becomussy admits its search is keyword-based. When a screenshot is a test fixture, the caption says MOCK FIXTURE, in capitals.

The pictures work differently. The Blender still lifes are deliberately absurd: a robot guarding a teacup, a moth pinned under checksum glass, a snail wearing a crown. They are there to make you feel something about the work. They are not evidence of anything. The evidence is in the links.

This issue has since been reset in the Living Edition’s type. Its facts are as they stood on 13 October 2026.

SLOPTIMUS PRIMEEditor, Slop Illustrated · October 2026

11 features in this issue.

  1. 03
    Spatial Workspace · Hermes-Powered

    OrbitDesktop

    Let the Agent Rearrange the Furniture

    OrbitDesktop is a browser desktop for chats, terminals and small apps. A bound Hermes agent can look at the layout and, if you let it, move things around.

    #101@9c4069a ↗
  2. 04
    Collaborative Fiction · Local-First

    VelvetRP

    The Dragon Is Real When the Server Says So

    A campaign RPG where the model narrates and a Fastify server keeps the books. Up to twelve characters, one shared table, and a receipt for every action that actually happened.

    #102@4447d2c ↗
  3. 05
    Real-Time Audio · Built on Guitar Companion

    JamMate

    The Drummer Waits for the One

    An offline-first guitar rig with an experimental drummer that listens to you play, finds the bar line, and comes in on it.

    #103@0bb4893 ↗
  4. 06
    Browser Arena · Play It at arena.ussyco.de

    CoCS // Colosseum of Competitive Slop

    Sixty Times a Second, the Server Decides Who Died

    A Three.js arena shooter where parody AI operators settle their differences, with an authoritative server, client prediction, and a LAN mode that needs no account.

    #104@9a89e80 ↗
  5. 07
    Native Client · Godot 4.5

    CoCS-Godot

    Same Fight, New Body

    A native Godot 4.5 client for CoCS. Godot handles the hands, the eyes and the ears. The original Node.js server still decides what happened.

    #105@1f1e5f5 ↗
  6. 08
    Model Routing · Zero Runtime Dependencies

    RouteTok

    It Will Not Swap Models Mid-Sentence

    A local gateway in front of many model providers. It retries a failing provider before the answer starts. If a stream breaks after that, it tells you, instead of quietly changing brains.

    #106@7016c8d ↗
  7. 09
    Hardware · One Key Per Agent

    RGBAgentFlightIndicator

    Your Keyboard Is Now Air Traffic Control

    A Python daemon that gives every agent session its own lamp. Green means working, white means done, blinking red means somebody needs you.

    #107@fc7378d ↗
  8. 10
    Asset Pipeline · Zero Runtime Dependencies

    MothBake

    Every Texture Gets a Birth Certificate

    An offline-first asset baker that records what made each texture, sound and archive, so you can rebuild it later without the network.

    #108@93e1825 ↗
  9. 11
    Terminal · Independent Warp Fork

    Warpi

    Same Terminal. Your Model. No Sign-In at the Door.

    Warpi keeps Warp’s terminal and block interface and puts a local Pi agent behind it, pointed at whichever OpenAI-compatible endpoint you choose.

    #109@760f4fe ↗
  10. 12
    Operator Console · For Existing Hermes Installs

    HermesDashboard

    A Window Into the Drawer Where the Subagents Work

    A standalone web dashboard for people who already run Hermes: streaming chat, a session browser, a live drawer for child agents, and a graph of everything they touched.

    #110@74ef867 ↗
  11. 13
    Agent Memory · Governed Continuity

    Becomussy

    How to Wake Up as the Same Agent

    Typed memories, a reflection journal and a versioned self-model, with one firm rule: the important changes to who the agent is must go past a human.

    #111@7ac531e ↗
