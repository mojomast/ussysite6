    The Money Isn’t Real Until It Falls Off the EdgeThe Money Isn’t Real Until It Falls Off the Edge

    Slot reels feed a pachinko field, the balls become coins on a pusher shelf, and your bankroll only moves when a coin actually drops over the lip. Play money, no accounts, no network calls.

    If you build a software factory, sooner or later someone asks to see a product. Jackpot Syndicate is one. It is a browser game with a very particular shape: slot reels feed a pachinko pinfield, the orbs spawn tokens on a coin-pusher shelf, and cash is banked only when a token crosses the pusher lip. Anyone who has stood at a seaside arcade watching a coin hang over the edge for a full minute understands the design immediately. It is play money. There are no accounts, purchases, ads or runtime network calls.

    The factory’s habits show everywhere. Separate harnesses check gutter rake, reel hit rates and bot balance against named acceptance criteria. A script measures the gzipped build against a 3 MB budget. A committed golden replay records a winning run at the current hash. The latest commit checks the bankroll against every announced bankroll change, because a coin-pusher game that miscounts coins is just a sad sculpture.

    Our favourite part is the verification table in the README. It records what was run for one documentation task on 15 November, and nothing else. Lint, typecheck, build and 226 tests passed. Four sprites are still vector placeholders. Vite grumbled about a large chunk. Everything that wasn’t rerun says NOT RUN, in capitals. It is the least glamorous table in the issue and we would frame it.

    Under the hood

    • Monorepo split between `packages/` (deterministic simulation, physics rake, animation) and `apps/game` (browser presentation, save safety, accessibility audit `a11yAudit.ts`).
    • Content-addressed sprite atlas (`apps/game/public/atlas/asset-manifest.json`): hashes every asset (`0bebb5ed6cc8-trinket.gold-peg-alchemist.png`, `1a6ea3b72c3c-trinket.midas-lip-sensor.png`) and resolves 67 locked renders alongside 4 explicit placeholders.
    • Strict bankroll accounting (`b8cd1fe`): tests verify bankroll state transitions against every announced bankroll change, tokens teetering on the shelf are unbanked until they clear the lip.
    • Offline-only play-money boundary: zero telemetry, zero remote calls, zero monetization.

export function measureBundle(distDir: string): BundleReport {
  const files = walk(distDir)
    .map((file) => {
      const raw = readFileSync(file);
      return {
        path: relative(distDir, file).replaceAll('\\', '/'),
        rawBytes: raw.byteLength,
        gzipBytes: gzipSync(raw).byteLength,
      };
    })
    .sort((left, right) => right.gzipBytes - left.gzipBytes);
  const rawBytes = files.reduce((total, file) => total + file.rawBytes, 0);
  const gzipBytes = files.reduce((total, file) => total + file.gzipBytes, 0);
  return { distDir, files, rawBytes, gzipBytes, budgetBytes: BUNDLE_BUDGET_BYTES, withinBudget: gzipBytes <= BUNDLE_BUDGET_BYTES };
}

    What it actually does

    • Three-stage deterministic arcade loop: slot reels feed a pachinko pinfield whose orbs spawn tokens onto a moving coin-pusher shelf
    • Committed golden Victory replay fixture verified across Chromium (10/10 E2E), Firefox (10/10 E2E), and WebKit (1/1 golden replay)
    • Dedicated simulation harnesses for gutter rake (sim:rake), 3×3 hit-rate (sim hitrate), bot synergy balance (sim balance), and worst-case tick timing
    • Automated gzip bundle-budget auditor (apps/game/scripts/bundle.ts) enforcing a 3 MiB ceiling and bankroll invariant assertions (b8cd1fe)

    What it doesn’t do (yet)

    • For that documentation task, the README lists the sim reports and the full WebKit journeys as NOT RUN, rather than carrying old green checks forward.
    • Four of the 71 sprite keys are generated vector placeholders. Art credits are in docs/ASSET_CREDITS.md.
    • The build triggers Vite’s warning about a chunk over 500 kB; the gzipped total stays inside the 3 MB budget.

    If you open the repo, start here

    • README.md: five-command quickstart and the T-092 conservative verification ledger.
    • apps/game/scripts/bundle.ts: 3 MiB gzip budget measurement across dist/.
    • docs/CONTRACTS.md & docs/ASSET_CREDITS.md: Rizzstack contracts and 67/71 asset provenance.
