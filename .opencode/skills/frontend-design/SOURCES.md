## Use in this project

Read the complete `SKILL.md`, then the project [research and direction record](../../../docs/editorial-audit/design-research-2026.md). The user's approved direction and preservation constraints take precedence over generic aesthetic defaults.

- Plan first: named palette, type roles, spatial concept, alignment, and the distinguishing idea. Review that plan against the actual publication before implementing it.
- Make the original biomechanical cover the memorable first-viewport subject. Use editorial hierarchy, imagery, and rhythm to carry the identity.
- Keep the six existing type roles across the issue; exercise restraint within each page. The skill's preference for one or two families is general guidance, not authority to discard the user's established roles.
- Preserve factual copy, source links, assets, controls, and prominent **Under the hood** disclosures. Copywriting advice is not permission to rewrite audited claims.
- Retain meaningful folios and section names. Eliminate redundant decoration rather than information-bearing navigation.
- Review desktop and mobile renders, focus, readable text, and reduced motion. The user-triggered disclosure transition is a useful state change, not a reason to animate every article entrance.

The companion [Impeccable references](../impeccable/SOURCES.md) add detailed typography, layout, reading, responsive, and review guidance. Use the two as complementary references to the same brief.
